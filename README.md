# Merge Sort Animation

A small browser-based Merge Sort animation. Enter 2–16 numbers separated by commas or spaces, then select **Generate Animation**. Use Play, Previous, and Next to move through the steps.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. After GitHub Pages publishes the site, use its URL in your report and QR code.
